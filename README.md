# Книга перемен — Telegram Mini App

Карты-предсказания по И-Цзин. Пользователь задумывает вопрос, вытягивает
одну из 64 карт, читает цитату, а затем переворачивает карту и читает
полное толкование.

Проект сделан на HTML, CSS и чистом JavaScript. В нём нет фреймворков,
npm-зависимостей и сборки: это набор статических файлов.

## Структура проекта

```
iching-cards/
├── index.html          разметка: стартовый экран и карта с двумя сторонами
├── css/
│   └── style.css       оформление, светлая и тёмная тема, анимация переворота
├── js/
│   ├── deck.js         логика: загрузка колоды, выбор случайной карты, разбор текста.
│   │                   Не обращается к странице, поэтому её можно тестировать в Node.js
│   ├── telegram.js     работа с Telegram: ready(), expand(), цвета темы, вибрация.
│   │                   В обычном браузере эти функции ничего не делают
│   └── app.js          связывает deck.js со страницей: кнопки, вывод текста, переключение экранов
├── tests/
│   └── deck.test.js    юнит-тесты логики и проверка данных колоды
├── cards.json          колода из 64 карт (id, title, quote, image, text)
├── images/             64 картинки hexagram-1.jpg … hexagram-64.jpg (896×1200, пропорция 3:4)
└── package.json        только сообщает Node.js, что файлы .js — это ES-модули (import/export),
                        и задаёт команду npm test. Зависимостей в нём нет
```

## Запуск локально

### Почему нельзя просто открыть index.html двойным кликом

При двойном клике браузер открывает файл по адресу вида `file:///Users/.../index.html`.
Для таких адресов браузер включает строгие ограничения безопасности:

1. **ES-модули не загружаются.** `<script type="module">` и `import` разрешены
   только для страниц, открытых по `http://` или `https://`. На `file://`
   браузер блокирует их с ошибкой CORS.
2. **`fetch('cards.json')` не работает.** Браузер не позволяет странице с `file://`
   читать другие файлы с диска через `fetch`. Иначе любой скачанный HTML-файл
   мог бы прочитать ваши личные файлы.

Локальный сервер отдаёт файлы по адресу `http://localhost`, как настоящий сайт,
и эти ограничения перестают мешать.

### Как запустить сервер

В macOS Python 3 уже установлен. Откройте терминал в папке проекта и выполните:

```bash
python3 -m http.server 8000
```

Затем откройте в браузере http://localhost:8000. Чтобы остановить сервер,
нажмите `Ctrl+C` в терминале.

Если установлен Node.js, можно использовать другой вариант:

```bash
npx serve .
```

Для проверки вёрстки под телефон откройте инструменты разработчика
(`Cmd+Option+I` в Chrome) и включите режим устройства (`Cmd+Shift+M`).

## Тесты

Тесты используют встроенный тест-раннер Node.js (`node --test`) и не требуют
сторонних библиотек. Нужен Node.js версии 18 или новее.

Установить Node.js на macOS можно через Homebrew:

```bash
brew install node
```

Запуск тестов из корня проекта:

```bash
node --test
```

Node.js сам найдёт файлы `*.test.js` в папке `tests/`. Тесты проверяют:

- в колоде 64 карты, у каждой есть все пять полей, а title, quote и text не пустые;
- id карт уникальны, а файл картинки каждой карты существует;
- в каждом толковании есть подзаголовок «Наставление»;
- выбранная карта всегда есть в колоде и не повторяется два раза подряд;
- граничные случаи: колода из одной карты, пустая колода, крайние значения случайного числа;
- разбор текста на абзацы и загрузка колоды (с подставной функцией fetch вместо сети).

## Публикация на GitHub Pages

Telegram открывает Mini App только по адресу `https://`. GitHub Pages
бесплатно выдаёт такой адрес для статических файлов.

1. Зарегистрируйтесь на https://github.com, если у вас ещё нет аккаунта.
2. Нажмите **+** → **New repository**. Укажите имя, например `iching-cards`,
   выберите **Public** и нажмите **Create repository**.
3. В терминале в папке проекта выполните команды (вместо `ВАШ_ЛОГИН`
   подставьте свой логин на GitHub):

   ```bash
   git init
   ```
   ```bash
   git add .
   ```
   ```bash
   git commit -m "Первая версия Mini App"
   ```
   ```bash
   git branch -M main
   ```
   ```bash
   git remote add origin https://github.com/ВАШ_ЛОГИН/iching-cards.git
   ```
   ```bash
   git push -u origin main
   ```

4. На странице репозитория откройте **Settings** → **Pages**.
5. В разделе **Build and deployment** выберите **Source: Deploy from a branch**,
   ветку **main** и папку **/ (root)**. Нажмите **Save**.
6. Подождите 1–2 минуты и обновите страницу настроек. Появится адрес вида
   `https://ВАШ_ЛОГИН.github.io/iching-cards/`. Откройте его и проверьте,
   что карты вытягиваются.

После каждого `git push` сайт обновится сам через минуту-две.

Все пути в проекте относительные (`cards.json`, `images/...`, `js/app.js`),
поэтому сайт работает и в подпапке `/iching-cards/`.

## Подключение к Telegram

### 1. Создать бота

1. Найдите в Telegram бота **@BotFather** и нажмите **Start**.
2. Отправьте команду `/newbot`.
3. Введите отображаемое имя бота, например `Книга перемен`.
4. Введите username бота. Он должен заканчиваться на `bot`, например `iching_cards_bot`.
5. BotFather пришлёт токен. Для этого проекта токен не нужен, потому что у нас
   нет сервера, но никому его не показывайте: токен даёт полный доступ к боту.

### 2а. Кнопка меню (самый простой способ)

Кнопка появится слева от поля ввода в чате с ботом.

1. В @BotFather отправьте `/mybots` и выберите своего бота.
2. **Bot Settings** → **Menu Button** → **Configure menu button**.
3. Отправьте адрес страницы: `https://ВАШ_ЛОГИН.github.io/iching-cards/`.
4. Отправьте текст кнопки, например `Вытянуть карту`.

Откройте чат с ботом и нажмите кнопку: приложение откроется внутри Telegram.

### 2б. Mini App со своей ссылкой

Так у приложения появится прямая ссылка вида `t.me/iching_cards_bot/cards`,
которой можно делиться.

1. В @BotFather отправьте `/newapp` и выберите бота.
2. Введите название и короткое описание приложения.
3. Загрузите картинку 640×360 пикселей (обложка приложения).
   Шаг с GIF можно пропустить командой `/empty`.
4. Отправьте адрес страницы `https://ВАШ_ЛОГИН.github.io/iching-cards/`.
5. Введите короткое имя для ссылки, например `cards`.

BotFather пришлёт ссылку `https://t.me/iching_cards_bot/cards`.

### Что меняется внутри Telegram

Файл `js/telegram.js` определяет, что страница открыта в Telegram, и тогда:

- вызывает `ready()`, чтобы убрать заставку загрузки, и `expand()`,
  чтобы раскрыть приложение на весь экран;
- отключает сворачивание приложения свайпом вниз, чтобы оно не закрывалось
  при прокрутке толкования (в Telegram 7.7 и новее);
- берёт цвета из темы пользователя и перекрашивает страницу при смене темы;
- включает лёгкую вибрацию при вытягивании и перевороте карты.

После изменений на GitHub Telegram может показывать старую версию из кэша.
Полностью закройте приложение и откройте снова. На компьютере может
понадобиться перезапуск Telegram.
